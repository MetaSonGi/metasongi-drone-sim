# MetaSonGi Drone Sim

여러 기종의 드론을 개별 조종하고 군집 설정·훈련과 몰입형 FPV 비행을 연습하는 독립 Unity 시뮬레이터입니다.

## 현재 상태
저장소와 요구사항·개발 계획을 초기화했습니다. 실행 가능한 앱·Unity 프로젝트·하드웨어 연동은 아직 구현하지 않았습니다.

## MVP 개발 목록
- [ ] 드론별 기체 프로필: 질량·추력·속도·회전 성능
- [ ] 개별 드론 선택과 조종·훈련 기록
- [ ] 군집 구성원·간격·대형·리더·역할 설정과 프리셋 저장
- [ ] 군집 이동·대형 전환·분리·합류·충돌 회피 실험
- [ ] FPV 1인칭·외부 시점 전환과 장애물 비행 연습
- [ ] 코스 완주·충돌·시간·대형 유지 오차 평가

## 개발 순서
1단계: 단일 드론과 FPV 조종 → 2단계: 기종 프로필과 연습 코스 → 3단계: 군집 설정·훈련 → 4단계: 성능 평가와 선택적 학습 알고리즘.

## 설계와 프로젝트 경계
VR 전시 프로젝트와 분리합니다. 아바타 FPV 같은 몰입감을 참고하되 기체·캐릭터·환경은 독창적으로 제작합니다. 군집 훈련은 초기에는 시나리오 반복과 제어 알고리즘 평가를 의미하며, 강화학습은 선택적 후속 기능입니다. 게임형 비행부터 시작하고 실제 비행물리의 충실도는 별도로 검증합니다. 실제 드론 제어는 초기 범위에 포함하지 않습니다.
